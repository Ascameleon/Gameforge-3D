# Gameforge 3D — agent skills

Curated Agent Skills from [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills), stored in `.agents/skills/` for compatible coding agents.

Included: router, asset creation, UI/UX, performance optimization, procedural generation, shader programming, camera systems, and three.js scene, glTF and materials workflows.

## Usage
Compatible agents should read `.agents/skills/router/SKILL.md` first and then the smallest relevant skill. The repository was empty before this integration, so these files establish agent guidance only; they do not implement the generator, rendering pipeline, Android app or 3D export runtime.
