# Gameforge 3D

## Game-development agent skills

Curated Agent Skills from [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills), stored in `.agents/skills/` for compatible coding agents.

Included: router, asset-production guidance, UI/UX, performance optimization, and three.js scene, glTF and materials workflows.

## Usage
Compatible agents can read `.agents/skills/router/SKILL.md` first and then the smallest relevant skill. The repository was empty before this integration, so these files establish an agent-guidance foundation only; they do not imply that the application, generator pipeline, or 3D export runtime has been implemented.
